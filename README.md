# Salon Chaarisma Daaden

Die öffentliche Website für Salon Chaarisma in Daaden.

- Website: https://salon-chaarisma-daaden.vercel.app
- Online-Terminbuchung: https://dnfk.mitdenkt.io/

## Lokal starten

```bash
npm install
npm run dev
```

Vor dem Deployment können die Checks mit `npm run lint`, `npx tsc --noEmit` und `npm run build` ausgeführt werden.
